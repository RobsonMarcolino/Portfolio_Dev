## 🚀 Sobre o Projeto
Este é o código-fonte do meu portfólio pessoal, feito para exibir minha trajetória e listar os principais repositórios desenvolvidos ao longo da minha carreira. 

O layout foi desenhado focado em **estética premium, glassmorphism e animações avançadas**, com integração dinâmica da API do GitHub para carregar habilidades e repositórios em tempo real, garantindo que o portfólio esteja sempre atualizado com meus repositórios mais recentes.

## 🛠 Tecnologias Utilizadas
- **HTML5 & CSS3 Vanilla** (Sem frameworks para o máximo de performance)
- **JavaScript (ES6+)**
- **GitHub REST API** (Para o carregamento de projetos e skills automáticos)
- **Design System Customizado** (Variáveis CSS, CSS Grid/Flexbox)

## ✨ Principais Funcionalidades
- **Auto-Sync com GitHub:** Os repositórios são puxados diretamente do GitHub, com ordenação personalizada priorizando projetos principais (RaioXapp, NexusStore, etc).
- **Carousel Infinito:** Exibição dinâmica de linguagens e skills coletadas dos meus repositórios, mescladas com habilidades essenciais como IA/GenAI, Google Cloud, Azure, e Python Backend.
- **Responsividade Mobile:** Componentes isolados para rodar vídeos otimizados (*Video.mp4*) e layouts adaptados para telas menores (menor que 860px).
- **Interface Hacker/Tech:** Design inspirado em interfaces de sci-fi e terminais avançados com cursores customizados e partículas renderizadas em Canvas.
